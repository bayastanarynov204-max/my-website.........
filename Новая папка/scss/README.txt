AVION WEBSITE
=============

Files:
- index.html       Main page structure
- style.css        Ready-to-use compiled stylesheet
- main.js          Mobile navigation and newsletter interactions
- avangard.scss    Brand colours and shared styles
- header.scss      Header and navigation styles
- home.scss        Hero and benefits styles
- offers.scss      Product cards and collections
- news.scss        Newsletter styles
- footer.scss      Footer styles
- media.scss       Responsive breakpoints
- style-adds.scss  Utility and accessibility styles
- assets/          Cropped reference photos from the screenshots you supplied

To run:
1. Extract the ZIP file.
2. Open index.html in a browser (or use Live Server in VS Code).
3. Keep the assets folder next to index.html.

The page uses the Jost font from Google Fonts; an internet connection is needed for the exact font.
The included CSS works directly without compiling SCSS. SCSS files are source files for further editing.
